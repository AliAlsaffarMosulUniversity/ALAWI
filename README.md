# رئاسة القسم الذكية

## نموذج العبء التدريسي المعتمد

قسم «العبء التدريسي» يتيح تنزيل ملف الجامعة الأصلي، وإدخال ساعات التدريس والإشراف والأنشطة لكل تدريسي وفترة، وحساب النصاب حسب اللقب وسبب التخفيض وفق معادلات الملف المرفق. يتيح استيراد الملف المعبأ بعد المعاينة وتصدير سجلات الفترة إلى النموذج الأصلي مع الحفاظ على التنسيق والمعادلات والقوائم والملاحظات وإعدادات الطباعة. تصدير النموذج يستوعب 300 تدريسي لكل ملف، ويتطلب اتصالاً بالإنترنت لتحميل JSZip؛ الاستيراد يتطلب SheetJS. لا تُرفع بيانات الساعات إلى خادم.

اعتمد القسم والعام والفصل والدراسة قبل حفظ السجلات أو الاستيراد. العام الموجود في النموذج الأصلي هو 2025-2026. لا تُحوَّل حصص الجدول إلى ساعات عبء آلياً لأن تعريف الحصة مختلف. تُدخل الساعات مباشرة. الملف الأصلي مرفق أيضاً في مجلد المشروع باسم university-workload-template.xlsx دون تعديل.

## الإدارة واستيراد Excel

افتح «الإدارة واستيراد Excel»، ونزّل نموذج Excel، ثم عبّئه واختر الملف وحدد ورقة العمل. راجع المعاينة واضغط «اعتماد». يدعم XLSX وXLS، حتى 5 ميغابايت و2000 صف. يتطلب تحميل قارئ Excel من CDN الرسمي لـSheetJS اتصالاً بالإنترنت؛ تبقى بيانات الملف في المتصفح.

الاسم مطلوب. الأعمدة الاختيارية: أيام التواجد، اللقب العلمي، التخصص، البريد الإلكتروني، الهاتف. الأسماء المكررة تُستبعد ولا تُحدَّث السجلات القديمة. اترك الهاتف بتنسيق نص في Excel للمحافظة على الصفر الأول. الأيام الفارغة مقبولة للاستيراد لكن يجب تعبئتها قبل إنشاء جدول. هذا قسم إداري في النسخة المحلية وليس صلاحيات دخول آمنة.

نسخة تجريبية عربية أُعيد بناؤها من وصف المشروع؛ ليست استعادة للملف الأصلي المفقود.

افتح index.html بمتصفح حديث. جميع البيانات تحفظ محلياً في المتصفح، ولا تتزامن بين الأجهزة. ابدأ بإضافة التدريسيين وأيام التواجد، ثم المواد والجداول والتكليفات.

الوظائف: دليل التدريسيين، تبليغات نصية مع تسجيل أسماء المرفقات، تأكيد قراءة تجريبي، صوت أثناء فتح الصفحة، جدول أولي يمنع تعارض التدريسي والقاعة، مراقبات مع فحص التداخل، تكليفات ومتابعة تأخير، لجان، أسئلة وإجابات، تصدير CSV ونسخ احتياطي JSON.

أيام التواجد: الأحد، الاثنين، الثلاثاء، الأربعاء، الخميس. افصل الأيام بفاصلة عربية أو إنجليزية. خوارزمية الجدول أولية وتعرض الحصص التي تعذر إدراجها؛ لا تضمن إيجاد أفضل توزيع ممكن. فحص المراقبات مستقل عن جدول المحاضرات.

تبديل العرض ليس نظام صلاحيات. لا يوجد تسجيل دخول آمن أو خادم أو رفع فعلي للمرفقات أو إشعار بين الأجهزة. لا تستخدم بيانات حساسة. صدّر نسخة احتياطية دورياً؛ حذف بيانات المتصفح يفقد السجلات المحلية.

للنشر على GitHub Pages: ارفع الملفات إلى الفرع main، ثم Settings → Pages → Deploy from a branch → main → /(root) → Save، وانتظر اكتمال البناء قبل التحقق من الرابط.
